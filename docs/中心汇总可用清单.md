# 中心汇总 · 可用清单（对本项目）

> 盘点时间：2026-11-04　来源：本机「中心汇总」素材库（39 个编号目录 + freellmapi / 阿晓的Trae / deliver 等）
> 判断标准只有一条：**能不能让「阿晓网关助手」这个单 exe 工具更省事、更准、更好看。**
> 不能的写清楚为什么，不硬凑。

## 一、已经用上的

| 目录 | 用在哪 | 怎么用的 |
|---|---|---|
| `freellmapi` | **本地上游 + 组件检测**（本轮新增） | 它把 34 家免费厂商、635 个端点聚合成一个 `/v1`。已加成上游预设「FreeLLMAPI（本地）」→ `http://127.0.0.1:3001/v1`，并在「融合组件」里按 3001 端口探测；没装就显示「未安装」，不影响别的功能 |
| `20-Galaxy` | 全站微交互 | 3800 个独立组件样例，风格差异太大不能整包引入；取其共性——按下 `scale(.97)`、hover 抬阴影、焦点 3px 光晕 |
| `23-AwesomeDesignSkills` | 仪表盘布局 | 取 bento 思路：`1.35fr / 1fr` 不等宽两栏，窄屏回落单列 |
| `14-DiagramDesign` | 所有图表 | 「无阴影、扁平、一图一义」：Token 趋势、积分环形、各处横条都按这个来，不画 3D、不加投影 |
| `22-AwesomeDesignMD` | 设计令牌参考 | 与 `reference/switch-assets` 的 shadcn 令牌交叉核对，确认圆角/字号/间距取值一致 |

## 二、能用但还没用（按性价比排序）

| 目录 | 能做什么 | 代价 | 建议 |
|---|---|---|---|
| `24-安全审计技能-SecurityAuditSkill` | 对仓库做一次系统性安全审计（不只看明文密钥） | 低（22 个文件，纯规则） | **下一轮可做**：补进 `scripts/preflight.ps1`，发版前一键跑 |
| `13-端到端测试智能体-TesterArmyE2E` | 给 30 个页面写端到端用例，防「改一处崩三处」 | 中（要装 Playwright + 写 30 条用例） | 值得做，但先等页面结构稳定 |
| `38-官方技能库-AnthropicSkills` | 官方 skill 的写法规范 | 低 | 可用来重写「使用说明」的 25 条教程，让结构更统一 |
| `freellmapi` 的 catalog（474 模型族 / 635 端点） | 免费额度页的真实数据源 | **做不了** | 已核实：端点数据存在服务端 SQLite（`data/freeapi.db`），仓库里没有；`api.freellmapi.co` 不开放匿名目录。只能运行时调本地服务的 `/v1/models`，拿不到「每家免费多少」 |
| `01-网页抓取框架-Scrapling` | 抓那些没开放 API 的平台额度页 | 高（每家一个解析规则，页面一改就坏） | 暂不做，违反「别硬凑」 |
