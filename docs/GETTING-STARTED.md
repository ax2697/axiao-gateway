# 新手教程（从零到能用）

> 面向第一次接触的人。全程只需要 Windows 10/11，不用 Docker、不用 Python。

---

## 第 0 步：准备两个东西

1. **便携版网关**（`WorkBuddy网关-便携版` 文件夹，里面有 `wb2api.exe` 和 `启动网关.bat`）
2. **阿晓网关助手**（`axiao-gateway.exe`）

把两个文件夹放在固定位置，例如：

```
D:\AI\
├─ WorkBuddy网关-便携版\
└─ 阿晓网关助手\
```

> 不要放 `C:\Program Files`（需要管理员权限，写配置会失败）。

---

## 第 1 步：启动网关

双击 `WorkBuddy网关-便携版\启动网关.bat`。

看到类似输出就是成功：

```
listening on 127.0.0.1:7863
```

⚠️ 这个黑色窗口就是服务本身，**用的时候别关**。

浏览器打开：`http://127.0.0.1:7863/panel/`
如果问密钥，填 `config.json` 里的 `api_key`（便携版出厂预置 `sk-QxgVEFVZM6Pg8Z6MfeiCA6TS`；开公网前请先改掉）。

---

## 第 2 步：添加账号（必须）

在面板右上角点「添加账号」：

1. 选 **国内版** 或 **国际版**
2. 点「获取授权链接」
3. 浏览器里登录你的 WorkBuddy / CodeBuddy 账号
4. 回到面板，账号会自动出现

> 账号池为空时，任何接口都会报“无可用账号”。这是新手最常见的坑。

---

## 第 3 步：打开阿晓网关助手

双击 `axiao-gateway.exe`。

左侧是分组菜单：

- **账号**：账号管理 / 切换 / 关联会话 / Token / 积分 / 免费额度
- **网关**：上游 / 协议 / 模型 / 成本 / 日志 / 配置
- **任务**：任务中心 / 签到 / 定时 / 钩子
- **系统**：导入导出 / 更新 / 组件 / 能力覆盖 / 说明 / 设置

第一次打开会自动读取便携版的账号和配置，不需要重新填。

---

## 第 4 步：签到

进入「签到中心」：

1. 顶部下拉选账号
2. 点「立即签到」——成功会显示返回 JSON
3. 想全部签：点「批量签到全部」

> 签到是原生直连 `copilot.tencent.com`，不启动外部 exe。

成长任务、旅行、抽奖在「任务中心」和「签到中心」的「一键成长任务」里。

---

## 第 5 步：接到客户端

进入「协议与路由」，看「接入信息」：

- **Base URL**：`http://127.0.0.1:7863/v1`
- **API Key**：点「复制密钥」
- **模型**：`http://127.0.0.1:7863/v1/models`

在任意支持 OpenAI 的客户端里填：

| 客户端 | 填法 |
|---|---|
| Cline / Cherry Studio / NextChat | 自定义 OpenAI，Base URL + Key |
| Claude Code | 「扩展能力 → 客户端配置导出 → Claude Code」 |
| Codex | 同上，选 Codex |
| DSH | 同上，选 DSH |
| Trae CN 桌面端 | 设置 → 模型 → 自定义模型 → OpenAI Chat Completions |

---

## 第 6 步：改配置

「网关配置」直接读写便携版 `config.json`，46 个字段分 5 块：

- 服务：监听、API Key
- 定时任务：签到/旅行/活跃/成长/保活
- 账号池治理：并发、熔断、冷却、积分保底
- 上游与高级：超时、UA、提示词、指纹脱敏
- 日志：保留天数、容量

改完点「保存配置」。部分字段需重启网关。

---

## 第 7 步：更新

「自动更新」列出 16 个组件（本应用 / panel / switch / 签到 / 12 个内核）。

- 点「刷新」检查 GitHub Releases
- GitHub 不通时，在上面填代理地址并保存

## 常见问题

**Q：双击 exe 没反应？**
看是否被杀毒软件拦截；首次运行可能慢几秒。

**Q：账号管理空白？**
确认便携版 `auths/` 里有 `workbuddy-*.json`，且网关已启动。

**Q：签到报 401？**
token 过期。到「签到中心」点「刷新 Token」，或重新授权账号。

**Q：接口报“无可用账号”？**
面板账号池为空，去面板添加账号。

**Q：端口 7863 被占用？**
改 `config.json` 的 `listen`，或设环境变量 `WB2A_LISTEN`。

**Q：换电脑要重新登录吗？**
整个便携版目录拷过去（含 `auths/`）就不用。

**Q：能局域网/手机用吗？**
「扩展能力 → 移动端常驻 → 开放局域网」，把 `listen` 改成 `0.0.0.0:7863`，手机访问显示的地址。⚠️ 公网使用必须配强 `api_key` + 反代。

---

## 安全提醒

- `auths/` 是明文 token，**不要外发、不要传网盘**。
- 默认只听 `127.0.0.1` 是安全的；改 `0.0.0.0` 前先配好密钥和防火墙。
- 本项目是非官方实现，可能违反上游条款，仅限本人账号自用。
